## How to Use

1. **Create Accounts**: Visit `/admin/test-accounts` to generate these accounts in Firebase
2. **Sign In**: Use any of the above email/password combinations
3. **Test Features**: Each account has realistic profile data pre-filled
4. **Role Testing**: Test different user flows for both job seekers and restaurants

## Admin Access

- Visit `/admin/test-accounts` to create all test accounts at once
- Use the "Show Passwords" toggle to view/copy credentials
- Create accounts by role (job seekers only or restaurants only)
- Real-time creation status and error handling

**Note**: If accounts already exist, the system will skip them gracefully.
